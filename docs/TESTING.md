## 重现自动验证

先按根目录 `DEPENDENCIES.md` 配置 Java 17 运行 Gradle、Java 8 toolchain。跨平台运行：

```text
./gradlew test nbtIntegrationTest
```

`nbtIntegrationTest` 自动编译独立源集、使用 Java 8 toolchain 和生成的运行 classpath，并将工作目录和 Minecraft home 都设为 `build/integration-run`。`check` 和 `build` 依赖该任务，因此 CI 会重跑真实 NBT 测试。`writeTestClasspath` 仅为诊断工具；运行测试不依赖本机固定路径。不要将独立启动器指向现有游戏实例或存档。

## 隔离游戏验收步骤（尚未执行）

请仅在新建 GTNH 2.8.4 实例与测试存档执行；不要替换现有 Mod 或使用生产存档。

1. 专用服务器加载 JAR，确认无客户端类加载异常，进入世界后检查六台控制器与配方注册。
2. 按搭建说明分别搭建六种结构；删除一个必要结构块或占据净空，确认机器停止加工且无输出。
3. 锻炉按配方输入准确材料、流体和 EU，记录输入输出与总能耗；加工中断电、拆结构和重载区块，确认没有免费进度、重复扣料或重复产物。
4. 填满输出槽并完成加工；重复按启动与领取按钮，再存档重载。腾出位置后只能取得一份输出。
5. 蜂群装配台使用可合成蓝图；缺失蓝图、材料或错误卡片必须拒绝启动。
6. 折叠工艺机完整执行工艺卡链，检查每一步 EU、主产物、副产物和流体；重载必须保留当前工序。
7. 回收器测试普通与精密配方白名单；不支持的物品不得回收。核算制造—回收环路，确保没有材料净增殖。
8. 探针执行各阶段任务，检查载荷消耗与解锁门槛；任务结束前后反复开关 GUI、重载并点击，奖励只入账一次。
9. 演算器完成、失败、玩家死亡、离线、离场和区块卸载各测一次；演算敌人不得掉落常规物品、经验或破坏方块，结束后必须清除。
10. 两位玩家同时操作同一台机器；距离或所有权不满足时按钮必须被服务端拒绝，不得重复领取。
11. 观察六机待机、启动、加工、缺料与完成视觉；确认服务端运行不依赖渲染类。
