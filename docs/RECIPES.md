# FluxArc 配方与研究手册（0.1.0）

本文件描述真实注册的机器配方。客户端的立体动画是这些服务器任务的表现，不是浏览器样片。目标环境为 GTNH 2.8.4 / Minecraft 1.7.10；不要把编译通过理解为已经通过整合包游戏实测。结构坐标与安装方式见项目主说明及结构说明。

## 基本操作

控制器槽 0 放蓝图或工艺卡（不消耗），槽 1—8 放材料，槽 9—14 接收产物。选择任务时请核对卡片、材料及流体。GT EU 输入能力、输出阻塞、结构状态会影响执行。完成之前不要拆除控制器。进度以服务器有效运行刻计数，不是现实墙钟；离线、区块卸载不提供免费进度。

下表时间为未调整配置时的基础时间，20 刻 = 1 秒。能量是阶段 EU/t × 阶段刻数之和。输出蒸汽的工艺必须预留 **16000 mB** 输出罐空间。机器不得向未加载的区块启动战斗。

## 从零起步与合成

六个控制器均使用以下 3×3 模板：

```text
钢板       电路       钢板
引力线圈   钢齿轮     引力线圈
钢板       选择物     钢板
```

锻炉与蜂群使用基础电路 `circuitBasic`；其余四台使用高级电路 `circuitAdvanced`。选择物：锻炉=活塞；蜂群=下界石英；折叠=末影珍珠；回收=燧石；探针=指南针；演算=钻石。六台均不依赖自身产出即可合成。

- 陶瓷板 ×4：红石粉在中心，8 个黏土球围一圈。
- 引力线圈 ×1：`铜单线 / 陶瓷板 / 铜单线`，`陶瓷板 / 铁锭 / 陶瓷板`，`铜单线 / 陶瓷板 / 铜单线`。
- 框架 ×4：5 根钢杆摆 X。
- 陶瓷构件 ×4：框架居中，8 个陶瓷板围一圈。
- 线圈构件 ×2：框架居中，左右引力线圈，上下陶瓷板。
- 轨道构件 ×4：两侧各 3 根钢杆，中间陶瓷板。
- 约束环构件 ×4：上下各 3 钢板，中排“引力线圈、陶瓷板、引力线圈”。

基础蓝图：上排“纸、金锭、纸”，中排“纸、红石粉、纸”，下排 3 张纸。

精密蓝图（无序）：基础蓝图 + 研究数据 ×2 + 继电组件 + 纸。合成会消耗旧蓝图，可重新合成基础蓝图。

量子蓝图（无序）：精密蓝图 + 轨道样本 + 精密核心 + 纸。

工艺卡（均无序）：钢铁卡 = 纸 + 铁锭 + 煤粉 + 红石粉；铜合金卡 = 纸 + 铜粉 + 锡粉 + 红石粉；矿物卡 = 纸 + 粉碎铁矿 + 红石粉。

## 1. 重力约束锻炉

每批消耗冷却水 250 mB，卡槽可空。展开 → 悬浮熔融 → 汇合 → 压制 → 冷却出料，普通成型共 480 刻 / 24 秒。

| 任务 | 输入 | 输出 | 主要加工 EU/t | 总 EU |
|---|---|---|---:|---:|
| 铁齿轮 | 铁锭 ×4 | 铁齿轮 ×1 | 32 | 12800 |
| 钢齿轮 | 钢锭 ×4 | 钢齿轮 ×1 | 128 | 43520 |
| 铁板 | 铁锭 ×1 | 铁板 ×1 | 32 | 12800 |
| 钢板 | 钢锭 ×1 | 钢板 ×1 | 64 | 23040 |
| 铜锡合金 | 铜锭 ×3 + 锡锭 ×1 | 青铜锭 ×4 | 128 | 48000 |

铜锡合金总计 480 刻，展开/熔融/汇合/压制/冷却分别 40/160/100/80/100 刻。铁/钢齿轮每个确实消耗 4 锭，无免费材料倍增。

## 2. 纳米蜂群装配台

| 蓝图 | 输入 | 冷却水 | 输出 | 阶段（EU/t × 刻） |
|---|---|---:|---|---|
| 基础 | 铁板 ×2、铜单线 ×2、红石粉 ×2 | 无 | 继电组件 ×1 | 展开16×40；线框32×160；装配32×240 |
| 精密 | 继电组件 ×2、钢板 ×4、基础电路 ×2 | 250 mB | 精密核心 ×1 | 定位64×80；校准128×200；层叠128×320 |
| 量子 | 精密核心 ×2、深空样本 ×1、钛板 ×4、高级电路 ×2 | 500 mB | 量子核心 ×1 | 展开128×80；线框512×240；封装512×400 |

继电组件用于探针、精密蓝图与核心；精密核心用于深空载荷、量子蓝图与量子核心。高阶核心还支持批量建设：精密核心居中、8个框架围一圈 → 约束环构件 ×16；量子核心居中、8个框架围一圈 → 线圈构件 ×32。核心内的钢板、电路、钛板及研究投入换取批量建造效率；这两种构件、核心及整台机器均不在回收白名单，不能分解循环刷钢材。

## 3. 维度折叠工艺机

这是固定受支持加工链，不能加速或代理任意外部机器。每条链消耗水 100 mB、输出蒸汽 16000 mB。中间工序保存在机器任务进度中，不能在工序中途取出并反复领取中间产物。

| 工艺卡 | 输入 → 输出 | 工序（EU/t × 刻） |
|---|---|---|
| 钢铁卡 | 铁锭 ×1 + 煤粉 ×1 → 钢锭 ×1 | 渗碳预热128×200；折叠锻炼128×800；水冷32×100 |
| 铜合金卡 | 铜粉 ×3 + 锡粉 ×1 → 青铜锭 ×4 | 混粉32×120；合金熔炼64×300；浇铸32×120 |
| 矿物卡 | 粉碎铁矿 ×1 + 煤粉 ×1 → 铁锭 ×1 + 石粉 ×1 | 洗选32×160；还原64×360；分离浇铸32×160 |

水/蒸汽体积使用 1:160 膨胀比例；工艺链消耗额外 EU，蒸汽不是无成本发电来源。石粉是明确的矿物链副产物。这里的渗碳工艺是 FluxArc 自有配方，不声称与所有 GT 原机的工艺条件相同。

## 4. 逆向解构回收器

回收仅匹配初始化时矿辞中选出的**一个准确物品及 metadata**，不按玩家自定义名称或其他 Mod 全体配方反推。带 NBT 的物品一律拒绝；工具、机器、容器及任意未知物品均不回收。普通模式卡槽空，精密模式放精密蓝图。

| 输入 | 普通回收 | 精密回收 |
|---|---|---|
| 钢板 ×1（制造需1锭） | 钢粒 ×6 | 钢粒 ×8 |
| 钢齿轮 ×1（制造需4锭） | 钢锭 ×2 | 钢锭 ×3 |

扫描100刻、分离180刻、封装80刻。普通32 EU/t，精密128 EU/t；均有材料损耗，不存在本目录成型—回收正收益循环。其他 Mod 若自行更改钢板/齿轮原料量，需由整合包作者重新审计。

## 5. 深空探针发射阵列

探针：上/下中心钢板，中排“陶瓷板、继电组件、陶瓷板”。

传感载荷：上/下中心玻璃，中排“铜单线、红石粉、铜单线”。采样载荷（无序）= 传感载荷 + 钢板 + 空桶 + 继电组件。深空载荷（无序）= 采样载荷 + 精密核心 + 钛板。探针与载荷都在任务中消耗，没有免费探针返回。

| 任务 / 卡 | 任务消耗 | 单次奖励 | 阶段（EU/t × 刻） |
|---|---|---|---|
| 近轨道 / 基础 | 探针 ×1、传感载荷 ×1 | 研究数据 ×2 | 充能128×200；发射128×80；测绘32×1800；回传32×120 |
| 空间采样 / 精密 | 探针 ×1、采样载荷 ×1、研究数据 ×1 | 轨道样本 ×2 | 充能128×240；发射128×80；采样64×3600；回收64×200 |
| 深空研究 / 量子 | 探针 ×1、深空载荷 ×1、轨道样本 ×1 | 深空样本 ×2 | 充能512×320；发射512×80；研究128×6000；回收128×240 |

可玩的解锁路径：基础蓝图 → 蜂群继电组件 → 近轨道研究 → 精密蓝图 → 精密核心及空间采样 → 量子蓝图 → 深空研究 → 量子核心。配方绑定载荷与目标，不能给错误载荷启动任务。奖励只能在服务器任务完成且输出有空间时结算一次。

## 6. 全息战术演算器

场域钥匙（无序）= 陶瓷板 + 红石粉 + 铁锭。站在结构指定空旷区域内选择任务，准备武器防具；敌人会实际攻击玩家，死亡与失败是实际风险。任务怪不给普通掉落或经验。

| 任务 | 卡片 | 费用 | 限时 | 胜利奖励 |
|---|---|---|---|---|
| 双哨兵 `sentinel_trial` | 基础蓝图 | 场域钥匙 ×1；32 EU/t | 60秒 | 战术数据 ×1 |
| 四重防线 `guardian_trial` | 精密蓝图 | 场域钥匙 ×2、研究数据 ×1；128 EU/t | 90秒 | 战术数据 ×3 |

玩家须本人击杀任务的 2 / 4 名 ArcSentinel。失败/超时/离开安全状态不退款，胜利奖励仅由控制器统一输出。战术数据 ×2 + 纸可无序合成研究数据 ×1；挑战也可提供一条带战斗成本的研究路线。任务怪与世界安全清理行为以实际控制器/挑战实现与测试记录为准。

## 兼容与验证边界

加工产物优先取 GT 矿辞，如 `gearGtSteel`、`plateSteel`、`ingotBronze`。某原料/产物矿辞或所需流体不存在时，该加工配方不注册，`RecipeCatalog.skippedRecipes()` 返回跳过的 ID；不会创建空产物替代品。回收只接受这次注册选中的准确物品。该策略不能代替 GTNH 2.8.4 游戏运行验证，实际验证状态见项目测试报告。
