# FluxArc 六机搭建图

所有坐标相对控制器中心，固定朝北（图上方 Z 负，右方 X 正），不随玩家朝向旋转。每幅图覆盖 X/Z=-4..4；每一层的行列位置相同。

图例：`C` 控制器，`F` 暗金属框架，`P` 陶瓷，`E` 线圈，`R` 轨道，`O` 分段约束环，`a` 必须为空气，`.` 不检查。控制器种类必须匹配机器。底部十字平台不是封闭外壳。

机器需要真实组件方块，动画本身不替代方块。任一指定组件缺失、错误或中心被阻塞即失效；相关区块未加载则不成立，不主动加载区块。

## 场域与动画

战术挑战额外需要内部 7×7 的 Y=0 实心可站立地板，以及 Y=1、Y=2 的净空；用普通完整方块补齐图中的点位，保留指定控制器和组件。挑战启动时检查碰撞与地板，失败不修改世界。敌人限制在场域内部。

六机客户端显示不同动画：锻炉弧形执行器、悬浮熔滴与冷却齿轮；蜂群双臂、逐层成型与微型执行单元；折叠机交错旋转环和当前工序指示；回收器扫描与分解；探针沿倾斜轨道发射并回收；战术场域扫描。控制器青色环表示正常，橙色表示缺料/断电/满输出，红色表示结构失效。停机状态停止加工动作，只有真实加工状态运行工作动画。

动画属于程序化 Minecraft 渲染，与先前概念视频不是同一引擎；实际游戏画面仍需客户端验收。
