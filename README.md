# FluxArc / 回响构装

独立的 GTNH **2.8.4 / Minecraft 1.7.10** 功能多方块附加 Mod。开发版 **0.1.0**。本工程不继承或修改 FluxLite、FluxDepths、FluxEcho、ChronoLink；视觉样片也保留为独立文件。

这是实际 Forge Mod 源码，包含六个控制器、五种结构构件、二十项显式加工/任务配方、服务端 EU 与材料处理、持久化状态和客户端 TESR。**尚未在完整 GTNH 客户端或专服中进行游戏验收，不能据此宣称可直接投入正式存档。**

| 机器 | 可用功能 |
|---|---|
| 重力约束锻炉 | 铁/钢齿轮与板材、铜锡合金；水冷与真实 EU；展开、悬浮、压制、出料 |
| 纳米蜂群装配台 | 基础/精密/量子蓝图；继电组件与两阶核心；机械臂逐层装配 |
| 维度折叠工艺机 | 三条限定工艺链；分阶段 EU、原料、水与蒸汽副产物；嵌套环显示阶段 |
| 逆向解构回收器 | 普通/精密白名单钢板与齿轮回收；不推导反向配方；拒绝带 NBT 材料 |
| 深空探针发射阵列 | 探针+不同载荷的三阶研究链；消耗、已加载 tick 计时、样本与蓝图解锁 |
| 全息战术演算器 | 双哨兵/四守卫真实战斗；专属敌人、真实攻击、受限场域、胜负与唯一奖励 |

## 安装与第一次使用

1. 在**新建的隔离 GTNH 2.8.4 测试实例**中放入 `FluxArc-0.1.0.jar`；不要直接拿正式存档验证。
2. GT 依赖锁定为 **GT5-Unofficial 5.09.51.482**。详见 [DEPENDENCIES.md](DEPENDENCIES.md)。不兼容其他 GT 版本的保证。
3. 用 NEI 查 `FluxArc` 合成控制器和构件。先用钢板、基础电路、引力线圈、钢齿轮及活塞合成锻炉控制器。无需其他 FluxArc 机器才能合成第一台。
4. 按 [结构逐层图](docs/STRUCTURES.md) 搭建。控制器是 `(0,0,0)`，结构固定世界朝北（负 Z）；图中净空必须保持空气。
5. 从控制器**侧面或底面**接 GT EU 电缆，顶部不接电。默认缓冲 4,000,000 EU，最高接受 8192 V；过压拒收，不爆炸。
6. 右键打开 GUI。最左是可重复使用的蓝图/工艺卡，中央八槽原料，右侧六槽产物，最右液桶槽。
7. 用单桶水放入液桶槽，或通过流体管向控制器输入。输入、输出罐各 32,000 mB；输出管可抽取蒸汽。液桶槽一次只处理单个容器。
8. 点击“配方”切换任务，“材料/结构”在聊天显示材料要求；放入材料后点击“启动”。Shift 点击物品可转移，蓝图请手动放置。

锻炉示例：选择铁齿轮，输入 4 铁锭与 250 mB 水，保持 EU 与结构有效，完成后得到 1 铁齿轮。默认 480 tick；实际按配置倍率变化。输出满时等待，不再次消耗材料或 EU。

完整合成、蓝图链和每台例子见 [配方说明](docs/RECIPES.md)。

## 状态与安全行为

- 启动只在服务端完整检查资源后，原子扣除物品与流体并持久化预留产物。重复启动不会再次扣料。
- 普通加工断电、拆结构暂停；修复后续做。已完成但输出满的任务保留待交付结果；结构有效且全部产物/流体均能容纳才一次性提交。
- 探针不是离线自动产矿：任务绑定载荷、研究层级，按已加载且有供电的服务器 tick 计时；卸载暂停，重载恢复。
- 折叠工艺是显式许可链，阶段、原料、流体和副产物固定；不会调用外部 TileEntity 的额外 tick。
- 回收率低于制造耗材；只认当前矿辞中确定的 item+metadata，拒绝 NBT。不会读取任意合成表来反解。
- 战斗必须在控制器周围 7×7 完整地板与两格空气中进行，外围 9×9 发射器。主人离线、死亡、跨维度、越界、缺电、拆结构、卸载或任务超时均失败。重载不续战、无奖励；战斗胜利后仍需付完配方 EU 和计时才能提交数据。
- 全息敌人无正常物品/装备/XP 掉落，不破坏世界，非主人不能伤害。清理只针对当前挑战的 UUID。
- 点击停止或破坏控制器会损失已预留的加工材料，不返还或复制；未预留的槽内物品正常掉落。罐内液体不随方块保存。

## 构建与验证

Java 17 运行 Gradle，Java 8 编译工具链。执行 `gradlew build` 输出重混淆 JAR；不要将 dev JAR 当游戏 Mod。依赖必须来自固定版官方 Maven/release。

已执行与未执行项见 [验证清单](docs/TESTING.md)。开发版没有宣称游戏帧率、完整整合包兼容性或 CI 通过等价实机通过。

配置：`config/fluxarc.cfg` 可调 EU/时间倍率、缓冲、最高电压与挑战开关；各字段有上下界。进行中的任务保存启动时倍率。
